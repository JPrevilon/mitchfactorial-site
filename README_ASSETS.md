# M!TCHFACTOR!AL Starter Assets

Drop this folder structure into the root of the Next.js repo.

Recommended usage:

- `public/assets/photos/hero-red-yellow-circle.png` — homepage hero / about feature
- `public/assets/photos/portrait-sunglasses-white-wall.png` — floating hero cutout candidate
- `public/assets/photos/dj-booth-bandana.png` — mixes/watch performance card
- `public/assets/photos/group-dj-booth.png` — Sistars/community card
- `public/assets/photos/urban-bench-portrait.png` — about/merch section
- `public/assets/photos/party-peace-bandana.png` — personality/archive card
- `public/assets/flyers/*` — events archive grid

Notes:

1. The screenshots are good enough for layout and MVP. Replace with hi-res originals before final public launch when possible.
2. If you make transparent cutouts, save them as:
   - `public/assets/cutouts/mitch-cutout-left.png`
   - `public/assets/cutouts/mitch-cutout-right.png`
3. If you make a local muted hero loop, save it as:
   - `public/assets/video/hero-loop.webm`
   - fallback `public/assets/video/hero-loop.mp4`
4. The source PDF is included under `/source` for reference.
